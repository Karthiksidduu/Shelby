# Automated Cryptanalysis of Classical Ciphers

Download [Cryptanalysis.html](Cryptanalysis.html), then double-click it.

The file opens in your browser as the app. The first open takes about a minute while Python loads. After that, use the pages in the left sidebar.

On Windows you can double-click [Cryptanalysis.bat](Cryptanalysis.bat) instead. On a Mac, double-click [Cryptanalysis.command](Cryptanalysis.command).

The project code is in [`cipher-cryptanalysis`](cipher-cryptanalysis).
